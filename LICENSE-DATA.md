# Data licence

The model outputs in `Previsao/Outputs/` (`article_*.csv`) are licensed under
the [Creative Commons Attribution 4.0 International licence (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

Some of these files contain the observed storage of the Cantareira System
(columns `y_true`, `y_base`), aggregated over its four reservoirs. That series
comes from operational records of Sabesp (Companhia de Saneamento Básico do
Estado de São Paulo), accessed through the Sabesp Decision Support System
(SSD). Credit it as: "Sabesp, via the Sabesp Decision Support System (SSD)".

The input data are not stored in this repository. They are published in
HydroShare, and each resource states the provenance and terms of every file
(see `README.md`, section *Data*).
