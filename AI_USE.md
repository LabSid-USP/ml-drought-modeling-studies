# Use of AI assistance

Parts of the code, documentation and data-packaging scripts in this repository
were written with the help of Claude Code (Anthropic), an AI coding assistant.
The assistant worked under written repository rules (`docs/methodological_rules.md`).
Among them: temporal splits on the target date, mandatory comparison with
persistence and climatology baselines, and non-causal reading of SHAP and other
explainability results.

The authors designed the study, defined the experiments, and reviewed and
validated all code and results. Models were checked against the persistence and
seasonal-climatology baselines, and the stored outputs were regenerated from
the code before release. The authors take full responsibility for the content.
